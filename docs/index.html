MAC Address Converter

v2.5.0

Lightweight Windows tray utility for converting MAC addresses between 10 formats — with a global hotkey, auto-cycling, and IEEE OUI vendor lookup. No admin rights required.

Download for Windows

System requirements: Windows 7 or later.

What it does

  • Cycles through 10 MAC address formats with one keystroke (default Alt+Shift+M)
  • OUI vendor lookup against the IEEE database (~38,900 vendors) — press Enter in the popup
  • Runs from the system tray — no admin rights required
  • Dark-themed Settings and About dialogs with persistent preferences
  • Optional autostart with Windows (Startup-folder shortcut, no registry writes)
  • Configurable hotkey, notification duration, and OUI auto-update interval
  • Single-instance enforcement — launching a second copy shows a notification and exits cleanly
  • Atomic settings & OUI writes with corrupt-file recovery
  • Update check on launch — prompts you when a new version is available (new in v2.5.0)
  • Works on corporate networks with TLS-intercepting proxies (Zscaler, Palo Alto, FortiGate, etc.) (since v2.4.3)

What's new in v2.5.0

  • Startup update check — the app fetches the latest release from the GitHub API on launch and prompts you with Upgrade / Skip buttons when a newer version is available. Silent on offline, rate-limited, or already-latest.
  • Single source of truth for the version string — APP_VERSION in update_check.py replaces three previously-hardcoded sites. Future releases bump one Python file instead of three.
  • Backfill highlights: v2.4.3 added truststore integration so the in-app OUI database download works on corporate networks; v2.4.2 fixed the Enter-to-vendor-lookup focus regression; v2.4.0 closed all 37 findings from a full security audit.

System requirements

  • Windows 7 or later (Windows 10/11 recommended)
  • No admin rights required
  • ~50 MB disk space
  • Internet connection for initial OUI database download (~3.5 MB)
